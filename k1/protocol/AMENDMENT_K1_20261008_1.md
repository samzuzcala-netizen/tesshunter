# AMENDMENT_K1_20261008_1 — QLP sectors 74-79 require the corrected v02 delivery

Dated 2026-10-08 (UTC), written before any calibration, injection, false-alarm, adversarial or
known-planet run (no light curve had been downloaded under K1 when this was written).

**Change.**  Section 1.1 (usable sector) gains one clause: a QLP product for sectors 74-79 counts
as usable only when it is the corrected v02 delivery (version `02` in the HLSP file name).  A v01
QLP product for those sectors is not usable; the sector then counts only if TESS-SPOC supplies it.

**Why.**  P12's frozen input policy (`p12/protocol/config.json`, `qlp_correction_required_sectors`
[74-79]; `input_identity_p12.timing_status` -> `CORRECTED_V02_REQUIRED`) requires the corrected QLP
products for those sectors because of a QLP timing correction.  The K1 usable-sector rule was
written from the review's summary, which lists only 80/83/85 and 99-104; omitting 74-79 would admit
a known timing defect that P12 already excludes.  This is a restriction, not a tuning choice.

**Effect on Part A.**  The target lists record sector membership, not product versions, so the
population counts (`n_usable`) cannot apply the clause; they count QLP 74-79 as usable.  The clause
applies at download time (realised products); every dropped v01 product is recorded in the
star's download receipt and the realised usable-sector count is the one used for calibration.
