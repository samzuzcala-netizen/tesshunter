# AMENDMENT_K1_20261011_4: what a "path" is for an adversarial negative (G3, E2)

Dated 2026-10-11 (UTC). Written before any Part F run: no HELD-OUT search exists and the HELD-OUT truth
is sealed. Rule STOP-G applies because the registration does not define the term.

**Gap.** Section 1.5 defines a matched path for a planet (identity rule 2.2). G3 ("at most 5% have a path
reaching SUBMIT") and E2's pass-through use "path" for adversarial negatives without defining it.

[M] One HELD-OUT host, TIC 232612416, is in both HELD-OUT sets: it is a known-planet host and an
adversarial EB. On that host, "any candidate reaching SUBMIT" could be the real planet.

**Clarification.**

1. For an adversarial negative, a path is a candidate matched by rule 2.2 to that negative's truth
   signal. That signal is the catalogued EB ephemeris (for blends, the neighbouring EB's ephemeris),
   with T14 from the catalogue, or 0.1 P when absent.
2. Candidates matched by rule 2.2 to a known planet of the same host are never counted as adversarial
   paths.
3. G3 is evaluated on matched paths. The any-candidate count (every candidate on the host that is not
   matched to a known planet) is reported alongside, as a conservative bound.
4. One search per host serves both roles. TIC 232612416 is searched once (job `ho_k1_232612416`) and
   enters both ledgers.

[M] E2's DEV pass-through was 0/35 under the any-candidate count, so E2 is unchanged by this
clarification.
