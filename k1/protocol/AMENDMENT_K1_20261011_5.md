# AMENDMENT_K1_20261011_5: period-only matching for adversarial negatives

Dated 2026-10-11 (UTC). Written before the Part F prediction lock, with the HELD-OUT truth still sealed.
No G1-G3 number has been computed.

**Gap.** Amendment 4 defines an adversarial path as a candidate matched by rule 2.2 to the negative's
catalogued EB ephemeris. [M] The adversarial truth table built in Part C holds the catalogued period
only (`eb_period_days`; `k1/protocol/build_sets_k1.py` lines 265-325). No epoch or duration was
recorded, so rule 2.2's event-coincidence clause cannot be applied.

**Clarification.** For an adversarial negative, a path is a candidate whose period satisfies the period
clause of rule 2.2: |P_c / (r x P_EB) - 1| < 0.01 for some r in {1, 2, 1/2, 3, 1/3}. Candidates matched by
the full rule 2.2 to a known planet of the same host are still excluded. The any-candidate count (every
candidate on the host not matched to a known planet) is reported alongside and bounds the period-only
count from above.

**Effect.** Matching is looser than full rule 2.2, because epochs are not compared. That can only
increase the G3 count, so it is the conservative direction.
