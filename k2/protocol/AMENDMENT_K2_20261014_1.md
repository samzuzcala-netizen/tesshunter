# AMENDMENT_K2_20261014_1 - C1 bin errors: propagated, not in-bin scatter

Dated 2026-10-14 (UTC), written before any further C1 measurement.  Rule K-G (a registered definition proved
unusable as written).  Tags: [M] measured, [A] adopted, [I] interpretation.

## Change [A]
RULES_K2 2.1 defined the binned C input with `tesshunter.audit_prep.bin_lc`, whose bin error is the in-bin scatter
/ sqrt(n - 1) for >= 3 points.  For every variant (V1-V4) the bin error is now the propagated error of the mean
of K1's per-cadence errors, sqrt(sum e_i^2) / n (`c_input_k2.bin_series`, `BIN_ERRORS = "propagated"`).  Bin
grid, bin time (mean time) and bin flux (mean flux) are unchanged.  Nothing else changes: variants, order, the
adoption criteria (a)-(c), the timing check and the pricing are as registered.

## Why [M]
The 10-job V3 timing check, run as registered (label `rc_v3`, 2026-10-14 17:14-17:44Z):
* 5 of the 8 jobs that PASS in K1 FAIL under V3.  At the true period V3's SDE is 2-6 where K1's blind TLS
  found the signal at SDE 31-110 (e.g. inj_159287706_3: K1 SDE 94 at 0.862 d, V3 SDE 2.4 there).
* Cause: with 3 (600-s products) to 9 (200-s products) points per 30-min bin, the in-bin scatter is a very noisy
  error estimate.  In four of the flipped jobs the top 1% of bins carries 49-73% of the total chi-square weight
  (K1's native C input: 3-7%), so the blind TLS fit is dominated by a few bins.  `bin_lc`'s error model was
  built for 2-min data (15 points per bin).
* [I] Propagation is what binning K1's input means for its errors: each bin keeps K1's relative weight, scaled by
  1/sqrt(n).  It is not tuned to any outcome.  A diagnostic TLS on one job was started to confirm this, but it
  ran throttled in an unmanaged shell and was stopped unfinished.  The re-run below is the test.

## Procedure [A]
* The 10 first-registration receipts stay under label `rc_v3` as a record (V3 as first registered); they do not
  enter C1.
* V3 under this amendment runs on all 119 R-C jobs under label `rc_v3a`, starting with the same 10 timing jobs.
  The K-B pricing uses the `rc_v3a` timing.  V2 / V4 / V1, if needed, use the amended errors (labels `rc_v2a`,
  `rc_v4a`, `rc_v1a`).
* Disclosure: the amendment was written after seeing 10 R-C outcomes; C1 is still decided on all 119.
