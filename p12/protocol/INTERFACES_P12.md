## Shared contracts

- Imports use `p12_common`, never an unqualified historical `common`. No import starts a job, fetches a network resource or writes a historical path. Every import of audit_p5 must immediately call `redirect_audit_cache(audit_p5)` before work. Network enablement is explicit at worker execution, never import time.
- Paths in receipts are repository-relative POSIX strings; process identity is `{pid, create_time, command}` with exact command-line matching. JSON receipts carry UTC and allow no NaN. Source-hash maps are `{repo_relative_path: sha256}`; seals accept this map or `{sha256,bytes}` values when reading historical seals.
- Jobs files are lists of `{job_id, arguments, attempt, result_path, source_hashes}`. `arguments` excludes the interpreter, includes the worker script and its CLI arguments; attempts begin at 1. `source_hashes` pins the worker, its loaded P12 imports and relevant historical source. A manifest with empty or invalid hashes is refused for live work. Controller launch records freeze the entire jobs file and all source identities.
- Attempts record `job_id`, status (`COMPLETE`, `TIMEOUT`, `OPERATIONAL_UNKNOWN`, `INTERRUPTED_UNKNOWN`), attempt, deadline_s, UTC boundaries, wall_seconds, sampled CPU, identity, exit_code, result_path and result hash when present. Unknowns never mean misses. Closures record pending/completed/unknown counts, all_owned_workers_closed, source_hashes_unchanged and queue_hours; controller owns resource ledger while alive.
- Input identity follows the historical records/source/comparison structure unchanged, at `manifests/input_identity/tic<id>.json`; selected raw paths and SHA-256 plus source FITS paths/hashes, index hash, notice-snapshot hash. No raw array is returned until its hash, policy and preferred-source validity are checked. Native arrays contain time, flux, flux_err and sector.
- Search runtime = historical strict fields plus `run`; `preset` is exactly `survey_p10`; run resolves inside DATA. Guard is installed before runtime parsing and science imports. Job IDs distinguish injection and natural cases on the same TIC. Prediction lock waits for all terminal receipts, retains operational unknowns, validates result/input/source/I/O hashes, and exposes no truth to a worker.
- SML uses only qualifying policy-selected QLP sectors with DET_FLUX_SML finite fraction at least 0.9 of DET_FLUX. Author choice and other arrays remain unchanged. Inventory/store have no efficacy decision. Injection preparation follows `survey_p8.get_prepared`: policy products -> harmonise -> inject both streams -> build_prepared; frozen arrays searched blind. Scoring is evaluator-only after closure and prediction lock.
- Fixture tests write only under pytest temporary directories or p12, never data/survey or historical directories. They can monkeypatch module REPO/ROOT/DATA and module dependencies; no production bypass flag. Synthetic controller tests may run a dummy subprocess tree and must close it before returning. Live controller launches belong only to the lead after all lanes finish and tests/integrity pass.
- Agents do not open p9/truth, any sidecar, the TTT table or calibration truth files. Sealed input-status/prepared hashes and historical outcome rows explicitly required by a row's tests may be handled by scripts without printing candidate-level content. If a required test needs prohibited truth, report that dependency rather than opening it or weakening the test.
- Protocol provenance copies origins verbatim first, then limited edits. Import helpers from historical modules only when they cannot write sealed paths; inspect transitive imports. No science source under src/ or scripts/ changes.
- The lead alone executes live integrity and redirected P9 verification. The P9 verifier's mandated complete check set can read its historical material in a dedicated verification process; only counts/failure names return, never truth or candidate rows. This is distinct from a blind science worker.
